# Informatics Labs — ELEE 2045

Weekly lab journals from ELEE 2045 Embedded Systems at the University of Georgia. Each lab pairs an M5StickC Plus device with a Python or Arduino host program and walks through one connectivity / sensing technology per week.

---

## Lab Index

| Lab | Topic |
|---|---|
| [Lab 1](./lab1/) | Hello-world — Python and MATLAB scaffolding for the lab series |
| [Lab 2](./lab2/) | M5StickC Plus bring-up, library install, serial-port logging, reaction timer |
| [Lab 3](./lab3/) | MQTT light control with a Tkinter GUI |
| [Lab 4](./lab4/) | Pygame capacitor charge/discharge sim + Bluetooth-driven game |
| [Lab 5](./lab5/) | MediaPipe pose tracking + YOLOv5 multi-class detection with M5 input |

The ELEE 2045 [Final Project](../semester-project-jordan_ricky-main/) builds on all five labs.
