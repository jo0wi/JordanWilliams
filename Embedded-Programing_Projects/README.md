# Embedded Programming Projects

Embedded software projects spanning ESP32, M5StickC Plus, Raspberry Pi Pico, and a host-side cache simulator written in C. Projects are grouped by course inside [`CacheEmulator/`](./CacheEmulator/) — that folder is named for its first project and now hosts a broader portfolio of embedded work.

---

## Index

| Project | Platform | Summary |
|---|---|---|
| [ESP32 Air Quality Monitor](./CacheEmulator/Air_Quality_Sensor_Project/) | ESP32 | Multi-sensor IoT monitor (BMP280, DHT11, thermistor, dust sensor) with LCD + ThingSpeak cloud push. |
| [Cache Emulator](./CacheEmulator/Cache_Emulator/) | C / Linux | Set-associative cache simulator with LRU replacement; reads gzip memory traces. |
| [M5StickC Plus BLE Button](./CacheEmulator/M5Stick_Bluetooth_mod/) | M5StickC Plus | BLE GATT server streaming front-button state to any client. |
| [Informatics Labs](./CacheEmulator/Informatics_Labs/) | M5StickC Plus + host | ELEE 2045 lab journals — reaction timer, MQTT light, capacitor sim, MediaPipe + YOLO. |
| [Home Security Final Project](./CacheEmulator/semester-project-jordan_ricky-main/) | M5StickC Plus + Tkinter + YOLO | Group capstone: dual-camera person detection, Tkinter GUI, MQTT light control. |
